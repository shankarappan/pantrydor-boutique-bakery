# Pantry d’Or Boutique Bakery

A responsive, editorial storefront concept for Pantry d’Or Boutique Bakery in Rotorua, New Zealand. The design uses Pantry d’Or’s supplied identity and public product photography, with working navigation, product links, a mobile menu, and a lightweight demo cart.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run test:sites
```

The client-facing commerce links point to the existing Shopify store at [pantrydor.co.nz](https://pantrydor.co.nz).
